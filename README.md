# 🧘‍♀️ Pilates Consultório - Sistema de Gestão

Sistema completo para gestão de clientes e agendamentos de consultório de Pilates, desenvolvido com [Next.js](https://nextjs.org) e TypeScript.

## 📋 Funcionalidades

- **Gestão de Clientes**: Cadastro, edição e controle completo dos dados dos alunos
- **Agendamento de Aulas**: Sistema intuitivo para marcação e gestão de horários
- **Controle de Pagamentos**: Acompanhamento de mensalidades e pagamentos
- **Relatórios**: Visualização de dados e métricas do consultório
- **Interface Responsiva**: Acesso em desktop, tablet e mobile

## 🚀 Como Executar

### Pré-requisitos
- Node.js 18+ instalado
- NPM, Yarn, PNPM ou Bun

### Instalação

1. Clone o repositório
```bash
git clone [url-do-repositorio]
cd pilates-consultorio
```

2. Instale as dependências
```bash
npm install
# ou
yarn install
# ou
pnpm install
```

3. Execute o servidor de desenvolvimento
```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev
```

4. Abra [http://localhost:3000](http://localhost:3000) no seu navegador

## 🛠️ Tecnologias

- **Frontend**: Next.js 14 (App Router)
- **Linguagem**: TypeScript
- **Estilização**: CSS Modules / Tailwind CSS
- **Fonte**: Geist (otimizada pelo Next.js)

## 📂 Estrutura do Projeto

```
src/
├── app/           # Páginas e layouts (App Router)
├── components/    # Componentes reutilizáveis
├── lib/          # Utilitários e configurações
└── types/        # Definições de tipos TypeScript
```
